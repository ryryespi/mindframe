# Project Ariel

Project Ariel is a single-file, offline canvas. You place dots, lines, and circles on layers (you, and an AI partner that never moves your shapes). Shared structure shows up in gold: equal angles, equal circle ratios, and the same crossing pattern at any place or size. Names and thought files stay on this device.

This is conceptual, not validated science.
